NEWTON-SPIEGEL-RECHNER  v8.0.0 – Übersicht der Dateien
============================================================

Starten:   Desktop:  python newton_spiegel_rechner.py
           Web:      streamlit run app.py
Alle Dateien müssen im selben Ordner liegen.

Wo ändere ich was?
  Eine Formel / Rechenregel      → kern_optik.py, kern_foucault.py, kern_bau.py, kern_vergleich.py
  Ein Diagramm (beide Versionen) → diagramme.py
  Ein Text, eine Beschriftung    → texte.py (STRINGS)
  Version, Farben                → konstanten.py
  Aussehen/Bedienung Desktop     → newton_spiegel_rechner.py (Klasse App)
  Aussehen/Bedienung Web         → app.py (Funktion main)

Regel: Eine Rechenfunktion steht genau einmal (im Kern) – Desktop und Web importieren sie.
       Der Kern kennt weder Tkinter noch Streamlit.

Test nach jeder Änderung an der Rechnung (im Ordner tests):
  python baseline.py pruefen     → 236 Werte gegen sollwerte.json (soll: 0 Abweichungen)
Nach einer GEWOLLTEN Änderung der Rechnung neue Sollwerte schreiben:  python baseline.py sollwerte
